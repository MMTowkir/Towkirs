# Simple Landing Page

A simple, fast static landing page.

## Deploy on Cloudflare Pages (connected to GitHub)

1. Push this repo to GitHub.
2. In Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git.
3. Select this repository.
4. Framework preset: **None**. Build command: *(leave empty)*. Build output directory: `/` (root).
5. Deploy. You get a free `*.pages.dev` URL. Every push to `main` redeploys automatically.

## Edit

Edit `index.html` — headline, text, links, and email — then commit and push.
